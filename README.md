# Школьный звонок

Программа для Windows, которая даёт звонки на урок и с урока по расписанию. Работает в трее
(значок колокольчика рядом с часами), запускается сама при входе в Windows и **не требует прав
администратора**.

Вся программа — один файл `SchoolBell.exe` (~130 КБ). Нужен только .NET Framework 4.x, а он уже
встроен в Windows 10/11 (в том числе в Windows 10 IoT Enterprise LTSC).

**Скачать:** [SchoolBell.exe на странице Releases](../../releases/latest), или соберите сами
(см. «Сборка»).

## Установка

На школьный компьютер нужно перенести **только `SchoolBell.exe`** (с флешки, по сети или скачав
с GitHub). Больше ничего не нужно: настройки и расписание программа создаст сама при первом запуске.
Запустите файл двойным щелчком.

* **Обычный запуск (рекомендуется).** Программа предложит установиться в
  `%LOCALAPPDATA%\Programs\SchoolBell` и включит автозапуск через
  `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`. Права администратора не нужны ни при установке,
  ни при работе. Запускайте под той учётной записью, под которой компьютер обычно работает.
* **Запуск «от имени администратора».** Программа установится для всех пользователей в
  `C:\Program Files\SchoolBell` с автозапуском через `HKLM\...\Run`. Администратор нужен только
  для установки: сама программа при входе любого пользователя работает с обычными правами. Этот
  вариант нужен, если на компьютере запрещено запускать программы из папки пользователя
  (AppLocker / политики ограничения ПО).

Если нажать «Нет», программа запустится из текущей папки без установки. Автозапуск можно
включить позже: меню → Настройки → «Запускать при входе в Windows».

Повторный запуск новой версии `SchoolBell.exe` обновляет установленную программу.

## Меню (щелчок по колокольчику, левой или правой кнопкой)

* Состояние: какой урок идёт и когда следующий звонок.
* **Звонки включены** — общий выключатель (значок становится серым и перечёркнутым).
* **Не звонить сегодня** — например, в праздник; завтра звонки включатся сами.
* **1 смена / 2 смена** — включить или выключить звонки для отдельной смены.
* **Дни недели** — по умолчанию пн–пт; если учатся по субботам, отметьте субботу.
* **Изменить расписание…** — таблица уроков по сменам: можно менять время, добавлять уроки и смены.
  Длительность уроков и перемен считается автоматически.
* **Звук звонка** — электрический (классический) или мелодичный звонок, свой файл WAV/MP3,
  громкость, длительность.
* **Проверить звонок**.
* **Настройки** — автозапуск, запрет спящего режима, «включать звук Windows перед звонком»,
  журнал звонков, удаление программы.

Звонок звучит в начале и в конце каждого урока. Стандартное расписание:

| Урок | 1 смена     | 2 смена     |
|------|-------------|-------------|
| 1    | 08:00–08:45 | 14:00–14:45 |
| 2    | 08:55–09:40 | 14:55–15:40 |
| 3    | 10:00–10:45 | 16:00–16:45 |
| 4    | 11:05–11:50 | 17:05–17:50 |
| 5    | 12:00–12:45 | 18:00–18:45 |
| 6    | 12:55–13:40 | 18:55–19:40 |

Ступенчатый режим первых классов (уроки по 35 минут в первом полугодии) отдельными звонками не
подаётся. Если нужен, добавьте в «Изменить расписание…» отдельную смену с такими уроками.

## Звук

Оба встроенных звонка программа синтезирует сама: электрический звонок (молоточек бьёт по чашке
24 раза в секунду) и мелодичный звонок на четыре ноты (мотив Вестминстерских курантов, XVIII век,
общественное достояние). Поэтому никаких лицензий на звук не требуется. Можно выбрать и свой файл
(меню → Звук звонка → «Выбрать свой файл»): программа копирует его в папку настроек, так что звонок
не пропадёт, если вынуть флешку.

## Что важно знать

* **Компьютер должен быть включён.** По умолчанию программа не даёт ему уходить в сон (экран гаснуть
  может). Если компьютер всё же спал, пропущенные звонки не звенят задним числом. В журнале
  появится запись о перерыве.
* **Звук.** Перед каждым звонком программа снимает в Windows режим «без звука» и поднимает громкость
  до 50%, если она была меньше 10%. Отключается в настройках.
* **Точность** зависит от часов Windows. Проверьте, что время на компьютере правильное.
* **Значок не виден?** В Windows 10 новые значки прячутся под стрелкой `^` у часов. Перетащите
  колокольчик оттуда на панель задач.
* **SmartScreen / антивирус.** Программа не подписана цифровой подписью. Если Windows покажет «Windows
  защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Если антивирус
  блокирует файл, добавьте его в исключения.

## Файлы

* Настройки: `%APPDATA%\SchoolBell\settings.ini` (текстовый файл, у каждого пользователя свой).
* Журнал звонков: `%APPDATA%\SchoolBell\journal.txt`. Туда пишется каждый звонок, пропуски, ошибки
  и изменения настроек.

## Удаление

Меню → Настройки → «Удалить программу…», или «Параметры → Приложения» (программа там есть), или
`SchoolBell.exe /uninstall`. Если программа установлена для всех пользователей, Windows запросит
пароль администратора. Папка с настройками при удалении сохраняется.

## Сборка

```bat
build.cmd
```

Собирает компилятором C#, встроенным в Windows (`%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe`),
ничего устанавливать не нужно. Результат: `dist\SchoolBell.exe`.

Самопроверка без звука и без установки (расчёт расписания, сохранение настроек, WAV-файлы звонков,
картинки меню и окна):

```bat
dist\SchoolBell.exe /diag C:\temp\bell-diag
```

Результат — в `C:\temp\bell-diag\diag.txt`.
